Project Presentation

Climate Change Explained

Kodland Python Level 2 Final Project

1

What is my project?

My project is an educational website about climate change. The goal is to explain the topic in a simple and understandable way and then allow users to test their knowledge with an interactive quiz.

📚

Learn

Learn the basics of climate change.

🌍

Understand

Understand its causes and consequences.

🧠

Test

Test your knowledge with a quiz.

2

Who is the target audience?

The main target audience is children, teenagers and people who are beginners in the topic of climate change.

The information is intentionally kept simple so that users can understand the topic without needing advanced scientific knowledge.

👦

Children & Teenagers

Easy-to-understand explanations.

🌱

Beginners

A simple introduction to climate change.

🌐

Multilingual Users

German, English and Russian are supported.

3

How does the project work?

The website has different sections. Users can first read information about climate change and then go to the quiz.

Step 1

Open the website and choose a language.

Step 2

Read the information about climate change.

Step 3

Start the quiz and answer the questions.

Step 4

See how many questions you answered correctly.

4

Technology

I used several technologies to build the project. Python is responsible for the backend and Flask connects the backend with the website.

Python Flask HTML CSS JavaScript Jinja2
5

Will I continue developing it?

Propably yes. The current version is a basic learning platform, but it could become much larger in the future.

My goal would be to make the website more interactive and give users more possibilities to learn and track their progress.

6

Possible improvements

📚 More content

Add more topics about climate change, energy and the environment.

🎯 Difficulty levels

Add Easy, Medium and Hard quiz modes.

🏆 Ranking system

Allow users to save their scores and compare results.

👤 User accounts

Save learning progress and previous quiz results.

🎲 Random questions

Show different questions every time.

🌐 More languages

Add additional languages to reach more users.

Conclusion

My goal was to create a website that is both educational and interactive.

Users can first learn about climate change and then test their knowledge with the quiz.

During this project, I was able to practice Python, Flask, HTML, CSS and JavaScript.
